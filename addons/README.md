# Optional Compatibility Add-Ons

This folder contains separate FS25 mod packages that depend on `FS25_BgaExtensions` plus a specific optional provider mod.

Optional fillTypes must not be added to core XML. When a provider-specific route is safe and useful, put it in a small add-on package with explicit dependencies.

Active add-ons:

- `FS25_BgaExtensions_PotatoWasherCompat`
- `FS25_BgaExtensions_OrchardsGreenhousesCompat`
