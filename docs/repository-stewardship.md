## License Decision

No license has been chosen yet. Until a license is added, outside users should assume the repository is visible source, not open permission to reuse, redistribute, or modify.

Recommended choices to consider:

- MIT: permissive, simple, common for code.
- GPL-3.0: requires derivative code to stay open under the same license.
- CC BY-NC-ND 4.0: suitable for non-code assets or distributed mod packages when derivatives should not be redistributed.
- Custom split licensing: one license for code and another for art/assets/mod package distribution.
